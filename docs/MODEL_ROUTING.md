# AI Development Routing

Use the least expensive model that can reliably complete the task.

- Astra: system architecture, difficult cross-system design, major audits, novel simulation algorithms, final architecture review.
- Sol: complex implementation, multi-package integration, debugging, migration logic, security-sensitive reviews.
- Terra: normal feature implementation, components, tests, refactors with clear specifications.
- Luna: mechanical edits, data entry, formatting, repetitive content and low-risk cleanup.

Astra should define contracts and acceptance criteria, not spend premium tokens implementing repetitive UI or content.
